小さな会社のGA4・サーチコンソール、
毎月これだけ見れば
次の改善が決まる。

2026年10月3日
読了約7分
AIdealize編集部
この記事でわかること
  • 毎月見る数字は5つで足りる
  • 見る順番は「見つかる → 読まれる → 相談」
  • 数字から「次に直すページ」を決める3つのパターン
  • 月30分で回せる振り返りメモのひな形

GA4（Googleアナリティクス4）とサーチコンソールは入れてある。でも、開いてみると項目が多すぎて、何を見ればいいか分からない。結局、月に一度も開かなくなる。小さな会社では、とてもよくあることです。

毎月の振り返りで必要なのは、レポートを全部読むことではありません。「来月、どのページを直すか」を1つ決めることです。そのために見る数字は、5つで足ります。

毎月見るのは、この5つ

数字どこで見るか何が分かるか
1. 検索のクリック数と表示回数サーチコンソール「検索パフォーマンス」検索で見つかっているか
2. 検索語句（クエリ）の上位と、11〜20位のものサーチコンソール「検索パフォーマンス」→クエリ次に書く・直すテーマ
3. 入口になっているページGA4「レポート」→「エンゲージメント」→「ランディングページ」どこから読まれ始めているか
4. 問い合わせ・電話・LINEのタップ数GA4「イベント」（設定してあるもの）相談の手前まで来た人の数
5. 新規の相談数と、どこで知ったか社内の問い合わせ台帳仕事につながっているか

5つ目だけはGA4では分かりません。フォームの送信には営業メールやテストも混ざるので、届いた問い合わせを社内で分けて数えます。

見る順番は「見つかる → 読まれる → 相談」

上の表を、上から順に見ます。相談の数が少なくても、検索のクリック自体が月数十回なら、問い合わせが少ないのは自然なことです。その場合に直すのは問い合わせフォームではなく、見つけてもらう段階です。下の数字だけを見て判断すると、直す場所を間違えます。

期間は「先月」と「その前の月」、できれば「前の年の同じ月」と比べます。季節で動く業種（住宅、観光、飲食など）では、前月比だけだと判断を誤りやすいからです。

「次に直すページ」を決める3つのパターン

パターン1：表示は多いのに、クリックが少ないページ

検索結果に出ているのに選ばれていません。掲載順位が10位前後なら、ページのタイトルと説明文を、検索した人の言葉に近づけます。サーチコンソールで、そのページがどんな言葉で表示されているかを見て、いちばん多い言葉をタイトルの前の方に入れます。

パターン2：11〜20位にいる検索語句があるページ

あと一歩で1ページ目に乗る検索です。そのページに足りない情報（料金の目安、対応エリア、よくある質問など）を足し、関係する別のページからリンクを張ります。新しい記事を書くより、早く効くことが多いです。

パターン3：よく読まれているのに、先に進まない入口ページ

ブログ記事が入口になっているのに、サービスや事例のページへ進んでいない状態です。記事の途中に、読者と同じ悩みに合う事例やサービスへのリンクを1つだけ置きます。

無料・費用契約なし

見られる形に整えます。

GA4・サーチコンソール・問い合わせの記録から、毎月見る数字を絞った月次レポートやダッシュボードをつくります。

オンライン対応・押し売りなし

月30分で回せる、振り返りメモのひな形

数字を見たら、次の5行だけメモに残します。紙でも、表計算でも構いません。

【2026年10月の振り返り】 今月の数字　：検索クリック ○回 / 入口上位 ○○ページ / 問い合わせ ○件（新規 ○件） 先月との差　：クリック +○回、新規相談 ±○件 気づいたこと：「○○市 ○○」で15位前後。料金のページが読まれていない 来月直すもの：○○のページに料金の目安を足し、タイトルを変える（1つだけ） 結果を見る日：2026年12月の振り返りで、このページのクリックと順位を見る

ポイントは「直したこと」と「直した日」を残すことです。数字が動いたとき、何が効いたのかを後から確かめられます。一度に何か所も直すと、何が効いたか分からなくなるので、1か月に1つで十分です。

AIからの訪問も、ついでに見ておく

ChatGPTなどのAIの回答から、サイトに来る人も出てきました。数はまだ少なくても、どのページがAIに紹介されているかは、検索とは違う傾向が出ることがあります。GA4での見方はGA4の「AI Assistant」の記事にまとめています。

よくある質問（FAQ）

毎月どのくらいの時間がかかりますか？

慣れれば月30分ほどです。最初の1〜2回は画面の場所を探すのに時間がかかるので、見る画面をブックマークしておくと楽になります。

GA4とサーチコンソールの数字が合いません。

数え方が違うためで、合わないのが普通です。サーチコンソールは「検索結果でクリックされた回数」、GA4は「サイトに来た訪問（セッション）」を数えています。それぞれの中で、先月と比べて増えたか減ったかを見てください。

閲覧する権限がありません。

サイトを作った制作会社や、以前の担当者がアカウントを持っていることが多いです。GA4は「プロパティのアクセス管理」、サーチコンソールは「設定 → ユーザーと権限」から追加してもらえます。自社のGoogleアカウントにも権限をもらっておくと、担当が変わっても困りません。

まとめ

GA4とサーチコンソールは、全部を読む必要はありません。毎月5つの数字を上から順に見て、「来月直すページ」を1つ決め、直した日を残す。これを続けるだけで、数字は「眺めるもの」から「次の一手を決める材料」に変わります。

無料相談・費用契約なし

次の一手が決められないときに。
