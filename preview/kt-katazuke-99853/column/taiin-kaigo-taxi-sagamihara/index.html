退院の日の移動はどうする？介護タクシー・民間救急の選び方と料金

公開日：2026.10.16株式会社K&T

退院の日が決まったら、意外と困るのが「どうやって家に帰るか」です。車いすやストレッチャーが必要なとき、体調に不安があるとき、家族の車では難しいこともあります。この記事では、退院の日の移動手段の選び方をまとめました。

  2. 料金の目安

  4. 予約のコツ

移動手段の選び方

こんなとき目安
自分で座っていられる。乗り降りに少し手助けが要る介護タクシー
車いすのまま移動したい介護タクシー（車いすのまま乗れる車両）
寝たままで移動したいストレッチャーのある介護タクシー、または民間救急
酸素・点滴・吸引など、医療を続けながら移動したい民間救急（必要に応じて看護師や救急救命士が同乗）
遠方の病院へ移りたい（転院）民間救急、場合によっては飛行機での搬送

迷ったときは、病院の相談員（地域連携室）や、移動の会社に体の状態を伝えて相談するのが確実です。

料金の目安

介護タクシーの料金は、多くの場合「運賃＋介助料＋器材の料金」で決まります。K&Tの場合の例です。

項目料金（税込）
時間運賃（30分）3,550円
基本介助料1,000円
予約料300円
ストレッチャー4,000円
リクライニング車いす／酸素各2,000円
医療スタッフの同行（30分ごと）2,200円

例えば30分・10kmほどの移動なら4,850円です。くわしくは介護タクシーの料金をご覧ください。 最新の料金 要確認

介護保険・医療費控除は使える？

  • 介護保険：介護保険の指定を受けた事業者の「通院等乗降介助」なら使える場合がありますが、条件があります。K&Tの介護タクシーは自費のサービスのため、介護保険は使えません。
  • 医療費控除：病状などから電車やバスでの移動が難しい場合の、入退院・通院のための移動費は、医療費控除の対象になることがあります。領収書を保管しておき、くわしくは税務署または税理士にご確認ください。

予約のコツ

  1. 退院日が決まったらすぐ連絡：退院の時間帯は予約が重なりやすいので、早めの連絡がおすすめです。
  2. 体の状態を伝える：座れるか、車いすか、寝たままか、酸素などが必要か。
  3. 荷物の量を伝える：入院が長いと荷物が多くなります。
  4. 行き先の様子を伝える：エレベーターの有無、玄関の段差、ベッドの位置など。

施設への入居が決まっている場合は、お部屋の片付けもあわせてご相談いただけます（施設に入るときの片付けの段取り）。

まとめ

座っていられるなら介護タクシー、寝たままや医療が必要なら民間救急が目安です。退院日が決まったら早めに予約し、体の状態と荷物の量を伝えましょう。

退院の日の移動は、救急救命士が運転するK&Tにご相談ください。
