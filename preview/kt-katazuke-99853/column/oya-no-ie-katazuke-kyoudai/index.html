親の家の片付けで兄弟ともめないために。決めておく5つのこと

公開日：2026.10.16株式会社K&T

親の家の片付けは、物の量より「家族の気持ちのちがい」で手が止まることがよくあります。「全部捨てればいい」という人と「なるべく残したい」という人、近くに住む人と遠くに住む人。始める前にいくつか決めておくだけで、ずっと進めやすくなります。

この記事の内容
  1. 誰が「最後に決める人」か
  2. 費用を誰がどう負担するか
  3. 形見分けのルール
  4. いつまでに終えるか
  5. 家をどうするか

1. 誰が「最後に決める人」か

全員で一つずつ決めていると、片付けはなかなか進みません。「迷った物は誰が決めるか」を先に決めておくと、作業が止まりにくくなります。実家の近くに住んでいて、立ち会える人が担当になることが多いです。

2. 費用を誰がどう負担するか

業者に頼む場合の費用、ごみの処分費、遠方から通う交通費など。「均等に分ける」「相続の割合で分ける」「家を売ったお金から出す」など、先に決めておきましょう。見積りは書面でもらい、全員が同じ金額を見られるようにしておくと安心です。

3. 形見分けのルール

  • 欲しい物を先に出し合い、重なったら話し合う
  • 写真・手紙・アルバムは、すぐに捨てずに一度まとめておく
  • 値段がつく物（貴金属・骨董品など）は、形見分けか売るかを全員で確認する

相続の手続きが関わる財産（不動産・預貯金・価値の高い物）は、片付けより先に専門家（司法書士・税理士など）に相談すると安心です。

ご家族の話し合いがまとまったら、写真1枚からご相談ください。

4. いつまでに終えるか

親が施設に入る日、賃貸の退去日、家を売る日など、期限があると話が進みやすくなります。期限がない場合も「◯月までに片付ける」と目安を決めておくと、先送りを防げます。

5. 家をどうするか

売る・貸す・しばらく置いておく・誰かが住む。家をどうするかで、残す物も片付けの範囲も変わります。空き家のまま長く置く場合は、管理の手間や、管理されていない空き家への市の指導についても知っておきましょう（相模原市の空き家の制度）。

業者に頼むときも、家族の確認を大切に

K&Tでは、作業の前に「残す物」「探している物」をご家族と一緒に決め、当日も迷った物はご家族に確認しながら進めます。
