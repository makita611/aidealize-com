接客の進め方(たたき台)

誰が対応しても、同じ質・同じ順番で聞けるように ／ 内枦保住建 ／ 2026-09-25作成
これは叩き台です。質問の順番や言い回しは、実際の打ち合わせの録音(Plaud)と、大磯さんとのロールプレイで確かめながら、一緒に直していきます。

1. 全体の流れ

初回のご来社から、約3週間後の間取り・概算の提示までです。

  1. 事前
    事前記入シートを送る(意欲の高いお客様)5〜10分・選択式が中心。今の「基本情報アンケート」の置き換えを想定しています。
  2. 冒頭
    録音の許可をいただく「ご要望を聞き漏らさないよう、記録のために録音させてください」とお伝えします。許可がなければ録音せず、手書きのメモにします。
  3. 分岐
    お客様のタイプを見分ける雰囲気を見に来られた方(A)か、意欲の高い方(B)かで、進め方を変えます。
  4. A の方
    動画・完成写真と3Dパースで、世界観を見ていただく条件は深追いせず、次の相談の日を決めます。
  5. B の方
    ヒアリングブックの順番で聞く課題 → 予算・決裁者 → 時期・他社 → 要望の優先順位 → 土地 → 締め、の順です(下の3)。
  6. 事後
    録音をAIで整理し、聞き漏れを確認する熟練の方が10分ほど見て、足りない点は電話やLINEで補います。
  7. 3週間後
    間取りの絵と、総額の概算をお持ちする要望のA/B/Cを使って、予算に合わせて調整します。

2. お客様は2つのタイプ

9/18に伺った「初めて見に来られる方」と「紹介などで意欲の高い方」の分け方です。

A: 雰囲気を見に来られる方

目的
内枦保住建に共感してもらい、次の相談につなぐ
使うもの
動画・完成写真・3Dパース
担当
誰でも(3Dパースの説明は、少しずつ動画に置き換えていく)

B: 紹介などで意欲の高い方

目的
予算・要望・条件を、漏れなく聞く
使うもの
ヒアリングブック・A/B/Cカード
担当
誰でも(最初は熟練の方が同席し、少しずつ減らす)

3. ヒアリングブック(Bの方に、この順番で聞きます)

間取りの話から入らず、先に「課題」と「予算」を聞きます。要望が広がって予算を超えるのを防ぐためです。各項目は「聞けた・曖昧・未確認」で記録します。

1. 課題(なぜ家を建てたいか)
質問(そのまま読めます)聞く理由深掘りの例
家づくりを考え始めたのは、どんなきっかけでしたか本当の目的を知るいつ頃から/誰が言い出しましたか
今のお住まいで、一番困っていることは何ですか課題をはっきりさせるそれはいつ・どんな時に/放っておくとどうなりますか
新しい家では、どんな毎日を送りたいですか理想の暮らしを知る誰と・どこで・どのくらいの頻度で
2. 予算・決裁者(間取りより先に聞きます)
質問(そのまま読めます)聞く理由深掘りの例
総額のご予算の目安は、土地代を含めていくらくらいでしょうか総予算を知る建物だけ/土地込みのどちらですか
自己資金とローンは、どのくらいのご予定ですか。事前審査はお済みですか資金計画を知る頭金はいくらくらい/借入先は決まっていますか
月々のお支払いは、無理のない範囲でいくらまでですか無理のない支払額を知るボーナス払いは使いますか
最終的にはどなたが決められますか。ご両親のご意見や援助はありますか決める方を知るその方は次回いらっしゃいますか
打ち合わせで要望が増えて予算を超えそうな時、どこまで動かせますか予算超過への備え上限は動かせますか
3. 時期・他社
質問(そのまま読めます)聞く理由深掘りの例
入居はいつ頃をご希望ですか。その理由はありますか時期と制約を知るお子さんの入学/賃貸の更新など
他にも検討されている会社はありますか比較の状況を知るどこまで話が進んでいますか
会社を選ぶ時に、一番大事にしていることは何ですか選ぶ基準を知る価格・デザイン・人柄のどれが上ですか
4. 要望の優先順位(A/B/Cに分けていただきます)
質問(そのまま読めます)聞く理由深掘りの例
これだけは絶対に、というものを3つまで教えてください絶対に外せないこと(A)なぜそれが大事ですか/どなたのご希望ですか
できれば叶えたいことは何ですかできればのこと(B)予算が合えば入れたいですか
予算次第で、後からでもいい・諦められるものは何ですか後回しにできること(C)将来のDIYや追加でも大丈夫ですか
5. 土地
質問(そのまま読めます)聞く理由深掘りの例
土地は、すでにお持ちですか、これから探されますか土地の有無を知る所在地は/ご実家の土地ですか
面積と、道路との接し方は分かりますか(測った数字か、聞いた数字か)敷地の条件を知る間口・奥行/道路の幅
上下水の引き込みや、名義・相続の手続きは済んでいますか手続きの見通しを知る未了なら、いつ頃終わりそうですか
6. 締め(まとめと、次の約束)
質問(そのまま読めます)聞く理由深掘りの例
今日伺った内容をまとめます。〜〜という理解で合っていますか認識を合わせる違いがあれば、その場で直す
次回は約3週間後に、間取りと総額の概算をお持ちします。○月○日はいかがですか次の約束をする準備していただくものがあればお願いする
図面をお持ちする前に、他社さんとの比較は済んでいる状態でよろしいですか次に進む条件の確認まだなら、いつ頃までにお決めになりそうですか

このほか、聞かずに記録するものがあります: 同じ言葉を繰り返した話題、「絶対」「どうしても」と言った話題、ご夫婦で反応が違った点(「温度感メモ」)。文字にならない雰囲気を残すためです。

4. 初回では聞かないこと

次のことは、家の大きさと総額が決まってから、契約後の詳細設計で決めます。

  • キッチン・浴室のメーカーとグレード
  • 壁紙(クロス)・床材の種類と色
  • スイッチ・コンセントの位置、設備の型番
話が細かくなった時の言い方:
「そこは、家の大きさと総額が決まってから、詳細設計の打ち合わせで担当と一緒に決めていきますね。今日は、いちばん大事な『ご要望の優先順位』を先に伺ってもいいですか」

5. 要望の優先順位カード(A / B / C)

熟練の方が肌感覚で行っている「絶対に外せないものを残す」判断を、誰でもできる形にします。予算に合わせる時は、Cから調整します。

A: 絶対に外せない3つまで。ここは削らない。
B: できれば叶えたい予算に余裕があれば入れる。
C: 後回しにできる予算が足りない時は、ここから外す。後からの追加やDIYに回せるもの。

6. AIでできること

録音した打ち合わせを、「読むしかない文章」から、探せて比べられる記録に変えます。

録音Plaud
文字起こし自動
AIが整理聞き漏れ・予算・A/B/C・追加で聞くこと
熟練の方が確認10分ほど
結果のイメージ(架空の例です)
項目状態根拠の一言
家づくりのきっかけ聞けた「子どもが小学校に上がる前に」
総予算聞けた「土地込みで3,000万円くらい」
決めるのは誰か曖昧「親にも相談する」だけで、決める方が不明
他社との比較未確認話題に出ていない → 追加で聞く

「熱量の高い話題」も、繰り返しや強調した言葉から拾います(声のトーンそのものではなく、文字からの目安です)。

お客様の会話を外部のAIで処理するため、録音の許可の取り方と、記録の使い道の説明文を先に決めてから使います。

7. 一緒に決めたいこと

  1. 概算の伝え方坪単価ではなく、付帯工事・諸経費まで入れた「総額」を、幅をつけてお伝えする形にしてよいか
  2. 図面をお持ちする前の確認「他社さんとの比較は済んでいるか」を確認して記録する(手付金なしの、今の運用のままでできます)
  3. 録音の許可の取り方と、説明の文言Plaudの設定(AIの学習に使われない設定など)も、一緒に確認します
  4. 今の「基本情報アンケート」の中身事前記入シートに置き換えるために、現在の内容を教えてください

  3. 10/16
