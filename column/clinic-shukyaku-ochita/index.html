クリニック集客 / 原因の切り分け

クリニックの集客が急に落ちた。
最初に見る5つの数字と、
落ちた場所の見つけ方。

2026年10月9日
読了約6分
AIdealize編集部
この記事でわかること
  • 集客が落ちたとき、対策より先に「どの段で落ちたか」を特定する理由
  • Search Console・GA4・予約システム・Googleマップで確認する5つの数字
  • 落ちた場所ごとに、まず疑うこと

先月まで順調だった新患が、今月になって明らかに減った。こういうとき、多くの医院が最初に広告の追加やMEOの手直しに手を出します。ただ、どこで落ちたのかが分からないまま対策を打つと、お金と時間だけが出ていきます。

先に確認したいのは、患者さんが来院するまでの道筋のどこで減ったかです。この記事では、1時間ほどで落ちた場所を絞り込むための5つの数字を、見る順に紹介します。

まず前提：落ちた場所は4つのどれか

患者さんが来院するまでの流れは、大きく4段に分けられます。

  1. 検索結果やマップに、医院が表示される（表示回数）
  2. 表示された中から選ばれて、サイトに来る（クリック数・訪問数）
  3. サイトで予約や電話のボタンが押される（行動数）
  4. 予約が完了し、来院する（完了数）

落ちた段が分かれば、打つ手はほぼ決まります。段を特定する前の対策は、当てずっぽうになりがちです。なお、クリニックは季節や休診日の並びで来院数が自然に動くため、前年の同じ月と比べて本当に落ちているかを先に確認してください。

数字1：検索での表示回数（Search Console）

Googleが無料で提供しているSearch Consoleで、過去3か月の「表示回数」の推移を見ます。

  • 表示回数そのものが落ちている → 検索順位が下がった、または検索される言葉が減った
  • 表示回数は変わらないのにクリックが減っている → 数字2へ

表示回数が落ちている場合は、直近でサイトを作り替えた、URLを変えた、スマホでの表示が崩れた、といった変更がなかったかを確認します。サイト改修の直後に順位が動くのは珍しくありません。

数字2：クリック率（表示された中で選ばれた割合）

同じSearch Consoleで、順位は上のほうなのにクリック率が極端に低い検索語がないかを見ます。当社のサイトでも、3位台で表示されていながらクリックが0という検索語が実際にあります。この場合、原因は順位ではなく、タイトルと説明文が、検索した人の知りたいことと合っていない可能性が高いです。

クリニックなら、診療科名・地域名・「予約」「初診」などの語が、タイトルの前半に入っているかを見直します。

数字3：サイトへの訪問数と、その入口（GA4）

GA4で、検索経由（Organic Search）の訪問数を前月・前年同月と比べます。次に、訪問の入口になったページ（ランディングページ）を見ます。

  • 診療案内や予約のページが入口になっているか
  • 院長あいさつやブログ記事ばかりが入口になっていないか

入口が記事ばかりだと、見に来た人は増えても予約には結びつきません。訪問数が横ばいなのに来院が減っているときは、この入口の偏りが原因のことがあります。

数字4：予約ボタンのクリックと、予約の完了数

ここが最も見落とされやすい箇所です。「予約ボタンのクリック数」と「予約完了数」は別の数字です。クリックは多いのに完了が少ないなら、予約フォームの手前で離脱しています。

  • スマホで実際に予約の最後まで進んでみる（自分の端末で、Wi-Fiを切った状態でも）
  • 予約システムの入力項目が増えていないか
  • 予約システム側のエラーやメンテナンスで、完了しない状態が続いていないか

サイトが見えなくなる、フォームが送れなくなる、といった事故は、気づかないまま数週間続くことがあります。証明書の期限切れなどの運用上の見落としも、ここで合わせて確認します。

数字5：口コミの件数と、直近の評価

最後に、Googleマップの口コミを見ます。件数が止まっていないか、直近の評価が急に下がっていないか。口コミは比較検討の最後に見られる情報なので、ここが弱いと、サイトまで来た人が他院を選びます。

ただし口コミは、集まるのを待つものではなく、患者さんに案内する導線を整えるものです。口コミ対応までやり切ったのに伸びない場合は、予約導線や商圏データの見直しに進みます。詳しくはMEO対策をやり切ったのに伸び悩む。次の一手は何をすべきかで解説しています。

よくある質問（FAQ）

対策の前に、そもそも「落ちた」のか確認する方法は？

前年の同じ月と比べるのが確実です。クリニックは季節や休診日の並び、花粉やインフルエンザの時期で来院数が自然に動きます。直前の月とだけ比べず、前年同月と、直近3か月の推移の両方を見て、本当に平常の波を外れているかを確かめます。

Search ConsoleやGA4が入っていない場合はどうすればいいですか？

まず予約システムの管理画面にある「予約完了数」だけでも、週単位で数えてください。Search ConsoleとGA4はどちらも無料で、あとから設定しても過去のデータは遡れないため、入っていなければ今日から入れておくのがおすすめです。

数字を見ても原因が分かりません。

落ちた段が特定できれば十分です。原因まで院内で突き止める必要はありません。「検索の表示は落ちていないのに予約完了だけ減っている」のように段が分かれば、専門家に相談するときも、確認する範囲が大きく絞れます。

まとめ｜対策の前に、落ちた段を特定する

集客が落ちたときの最初の仕事は、対策を打つことではなく、落ちた段を特定することです。5つの数字は、Search Console・GA4・予約システム・Googleマップを見るだけで揃います。

数字を見る作業を毎月続けるのは、院内だけでは負担になりがちです。AIdealizeでは、クリニックの集客でどこに取りこぼしがあるかを点検する、無料の分析を行っています。
