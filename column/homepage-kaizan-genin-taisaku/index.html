「ホームページが勝手に別のサイトへ飛ぶ」「検索結果に見覚えのない文字が出ている」——ホームページの改ざんは、被害に遭った本人が最後まで気づかないことの多いトラブルです。見た目が変わらないまま、裏側で広告や詐欺サイトへ誘導されているケースもあります。

改ざんの原因は、多くが「3つの放置」

🔑
① 管理画面のパスワードが弱い／ログイン画面が丸見え
WordPressなら、ドメインの後ろに /wp-login.php を付けるとログイン画面が開く状態が標準です。機械が何万通りものパスワードを自動で試します。
🧩
② CMS・プラグインが古いまま
更新されていないプラグインの“既知の弱点”を突かれる被害が非常に多く見られます。制作後に誰も更新していないサイトは要注意です。
🖥️
③ サーバー・FTPの管理が甘い
FTPのパスワード使い回し、不要になったテスト用ファイルの放置、共有サーバーの別サイト経由の侵入などが原因になります。

いずれも「特別な技術で破られた」のではなく、開いていた鍵を使われた形です。

5分でできる「改ざんされていないか」チェック

  • Google検索：site:自社ドメイン で検索し、見覚えのないページや外国語・薬品・賭博系の文字が出ていないか
  • 別の端末・別回線で開く：スマホ（Wi-Fiを切った状態）で開いて、知らないサイトに飛ばされないか。改ざんは「検索から来た人にだけ」表示される場合もあります
  • 管理画面に入る：身に覚えのない管理者ユーザーや、見覚えのない投稿・固定ページがないか
  • Search Console：「セキュリティと手動による対策」に警告が出ていないか
無料・入力30秒・費用契約なし

今すぐ、自社サイトの危険性をチェック

ドメインを入れるだけで、「誰でも管理画面に入れる状態になっていないか」「サイトの鍵（暗号化）が切れていないか」「古いシステムのまま放置されていないか」を、誰でも見られる情報の範囲で自動チェックします。

気づいたときの初動（順番が大切です）

  1. 現状を保存：画面のスクリーンショット、サーバーのログ。消す前に必ず
  2. パスワードを全部変更：管理画面・FTP・サーバー・データベース・メール
  3. 制作会社・サーバー会社に連絡：バックアップから戻せるか、侵入口の調査ができるかを確認
  4. CMS・プラグインを最新に：使っていないものは削除
  5. 個人情報が含まれていた場合：お問い合わせ内容などが漏れた可能性があれば、報告・通知の要否を専門家に確認
⚠ よくある失敗：見た目の不審ファイルだけ消して「直った」と思い、数日後に再発するケース。侵入口（弱いパスワード・古いプラグイン）を塞がないと、同じ手口でまた入られます。

再発・予防のための基本対策

  • 管理画面の保護：ログインURLの変更・アクセス制限・二段階認証
  • 更新の習慣化：CMS・プラグイン・テーマを定期的に最新へ（できれば保守契約に明記）
  • バックアップ：サーバーとは別の場所に、定期的に取得
  • 定点観測：年に数回、外から見える状態を点検する

よくある質問（FAQ）

ホームページが改ざんされたか、どう確認すればいいですか？

自社名や主要キーワードでGoogle検索し、タイトルや説明文に身に覚えのない文字（海外の商品名・賭博・薬品など）が出ていないか、スマホ・別回線からサイトを開いて見知らぬサイトへ飛ばされないかを確認します。Google Search Consoleに登録していれば、『セキュリティの問題』の通知も届きます。

改ざんされたらすぐ自分で消してもいいですか？

消す前に、証拠として現状を保存（スクリーンショット、サーバーのログ）してください。そのうえで管理画面のパスワード変更、CMS・プラグインの更新、不審ファイルの調査が必要です。侵入口を塞がずに消すだけでは再発することが多いため、制作会社・サーバー会社への連絡を優先してください。

ホームページが改ざんされたら、法的な報告は必要ですか？

個人情報（お問い合わせ内容など）が漏れた可能性がある場合は、個人情報保護法に基づく対応（個人情報保護委員会への報告・本人通知）が必要になることがあります。状況によって異なるため、早めに専門家へ相談してください。

まとめ｜改ざんは「気づく仕組み」と「鍵を閉める」で防ぐ

ホームページの改ざんは、原因のほとんどが「パスワード」「更新」「管理画面」の放置です。まずはsite:検索と、/wp-login.phpが開かないかの確認から始めてみてください。
